한영 키가 안 먹혀도,
친 대로 되돌려 드립니다.

가끔 한영 전환이 제때 안 먹는 건 macOS의 오랜 문제죠. 자판이 잘못 물린 채 친 글자를, 이 기기 안에서 판단해 제 글자로 바꿉니다. 한글이든 영문이든 양방향으로 — 다시 지우고 칠 필요가 없습니다.

새 소식

업데이트와 공지

무엇을 고치나

한 ⇄ 영, 자판만 잘못 선택한 글자를 되돌립니다.

키보드 배열은 그대로 두고, 입력 소스만 잘못 둔 채 친 글자를 자동으로 판단해 바꿉니다. 영문 자판으로 친 한글도, 한글 자판으로 친 영문도 모두 대상입니다.

dkssud안녕영 → 한
ㅗ디ㅣㅐhello한 → 영
gksrmf한글영 → 한
쟈랴wifi한 → 영
rkatk감사영 → 한

그게 다가 아닙니다

고치고 나면, 자판도 알아서 바뀝니다.

글자만 되돌리는 게 아닙니다. 한/영 입력 상태까지 의도한 언어로 함께 전환해, 고친 다음 글자부터 바로 이어집니다. dkssud를 안녕으로 고치면 그대로 한글 상태 — 한/영 키를 다시 누르거나, 지우고 다시 칠 필요가 없습니다. 교정 뒤 직접 자판을 바꿨다면 그 선택은 덮어쓰지 않습니다.

또 하나

한글 조합이 깨지는 앱, 그것도 잡습니다.

일부 앱은 macOS 한글 입력기의 조합을 제대로 처리하지 못해, 조합 중 글자가 안 보이거나 자모가 풀어써집니다. 문제가 있는 앱을 등록해두면 Mackor이 두벌식 조합을 직접 완성해 정상 글자로 넣어줍니다. 오타 교정과는 별개의 기능입니다.

CorelDRAW — 조합 중 글자가 보이지 않거나 자모가 빠질 때

Wine · CrossOver 앱 — 안녕이 ㅇㅏㄴㄴㅕㅇ처럼 풀어써질 때

IntelliJ IDEA의 일부 내장 브라우저(JCEF) 영역에서 조합이 깨질 때

사생활

친 글자는 이 기기를 떠나지 않습니다.

교정은 전부 당신의 Mac 안에서 이뤄집니다. 입력한 내용도, 교정한 결과도, 어떤 앱을 쓰는지도 서버로 보내지 않습니다. 네트워크를 쓰는 건 새 버전 확인과 새 소식 확인, 이 두 가지뿐입니다 — 둘 다 추적이나 식별자 없이 파일만 받아오고, 새 소식은 설정에서 끌 수 있습니다.

설치

세 걸음이면 됩니다.

01

받아서 엽니다

위 Mac용 다운로드를 누르면 바로 내려받습니다. 받은 파일을 열고 Mackor를 응용 프로그램으로 옮깁니다.

02

손쉬운 사용 권한을 켭니다

처음 실행하면 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 Mackor를 켜라고 안내합니다. 교정을 하려면 이 권한 한 번이 필요합니다.

03

메뉴바에서 조용히 동작합니다

이제 평소처럼 치기만 하면 됩니다. 적용 범위는 메뉴바 아이콘에서 앱을 가리지 않고 적용 또는 선택한 앱만으로 고를 수 있습니다.

미리 알아 두면 좋은 것

할 수 있는 것만 정직하게 적습니다.

캔버스에 직접 글자를 그리는 앱(예: Illustrator)은 자동 교정이 원리적으로 어렵습니다. 입력란이라는 것 자체가 없기 때문입니다.

앱을 방금 전환한 직후 첫 단어는 놓칠 수 있습니다. 다음 단어부터는 정상입니다.

어떤 앱에서 되는지는 실제로 쳐 봐야 확인됩니다. 안 되는 앱은 앱 안에서, 또는 GitHub Issues에 제보할 수 있습니다.

이미 예전 버전을 쓰고 있다면

CorelHangulFix · MacKR 사용자는 먼저 정리해 주세요.

예전 CorelHangulFix나 MacKR은 Mackor과 다른 앱이라 자동 업데이트로 넘어오지 않습니다. 옛 앱을 종료·삭제하고 시스템 설정 → 손쉬운 사용의 옛 항목도 지운 뒤 위 버튼으로 새로 설치하세요.

지우려면 앱 메뉴바의 앱 삭제 (Uninstall)가 가장 확실합니다. 자세한 정리 방법은 삭제 안내를 참고하세요.
